# WorldCache

## Files

- `index.html` — main page
- `style.css` — layout and visual styling
- `script.js` — interactive tabs, tables, charts, and lightbox
- `assets/brand/` — icon files in SVG and PNG
- `assets/figures/` — figures used on the site

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Edit

- Text and structure: `index.html`
- Results data and chart logic: `script.js`
- Styling: `style.css`
- Figures and icons: `assets/`
